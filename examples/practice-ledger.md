# 연습용 증거 지도

아래는 이 문서를 설명하기 위해 만든 가상 예시다. 실제 실행·사용자 경험·시험 결과가 아니다. 그대로 제출하거나 자신의 경험으로 표현하지 않는다.

연습 과제: 작은 CSV에서 지역별 요청 건수를 집계해 보는 도구.

| 요구사항 | 선택 | 확인 방법 | 가상 관찰 예 | 한계 |
|---|---|---|---|---|
| R-001 지역별 집계 | 명확한 키로 그룹화 | 4행 표를 손으로 집계해 비교 | A=3, B=1 | 대량 파일은 미검증 |
| R-002 빈 지역 처리 | 미분류 그룹 표시 | 빈 셀 한 행 입력 | 전체 건수에서 빠지지 않음 | 공백 문자열 정규화 확인 필요 |
| R-003 필터 결과 표시 | 필터 후 집계 재계산 | 지역 선택 전후 비교 | 선택 지역만 집계 | 다중 선택 미구현 |

AI 요청 예: “빈 지역을 제외해도 되는지 구현 전에 확인하고, 포함/제외가 전체 합계에 미치는 차이를 계산해줘.”

판단 예: 전체 건수를 보존해야 하므로 무조건 삭제하는 대신 미분류 그룹을 선택했다. 이는 업무 정의가 같은 경우에만 유효한 판단이다.

설명 예: “지역별 요청 수를 확인하는 도구입니다. 파일을 읽어 지역을 기준으로 묶고, 빈 지역은 미분류로 표시하도록 설계했습니다. 검증 시에는 작은 입력의 수기 집계와 프로그램 결과를 비교하면 됩니다. 실제로 비교한 결과를 기록한 뒤에만 정확히 동작했다고 말할 수 있습니다.”
