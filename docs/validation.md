# 배포 전 검증 기록

검증일: 2026-10-31. 로컬 Linux / Python 3.12 / PyMuPDF 1.27.2.3에서 확인했다. 실제 응시 환경을 대신하는 검증은 아니다.

## 실행 도구

`python3 -m unittest discover -s tests -v`의 15개 테스트로 다음을 확인했다.

- 기존 과제 지침·기록 보존과 선택 스킬 설치.
- 잘못된 스킬 이름, 경로 탈출, 외부 symlink 쓰기 거부.
- 실제 실행 출력·종료 코드·로그 해시 저장.
- 실패 명령, 시간 초과, 없는 실행 파일 처리.
- 같은 검증 ID의 덮어쓰기 방지.
- 코드 변경·로그 변경·없는 필수 파일의 점검 실패.
- 추적 파일 없는 기록·요구사항 불일치·잘못된 JSON 구조의 오류 표시.
- 셸 메타문자를 명령으로 해석하지 않는 인자 전달.

별도의 임시 연습 작업 공간에서 doctor → init → 작은 계산 모듈 테스트 → manifest 작성 → audit을 실행했다. 정상 비율과 0분모 사례를 검증하고 `RECORDED_CHECKS_OK`를 확인했다. 설치한 문서의 로컬 링크도 확인했다.

## 스킬과 자료

12개 스킬에 skill-creator의 quick_validate를 실행해 이름·frontmatter 형식을 확인했다. 저장소 검사 도구로 로컬 링크, 스킬명 중복, 6개 출처의 커밋 고정, PDF 존재를 점검했다.

스킬의 합성 평가 시나리오를 작성하고 지침의 범위·실전 제한·증거 표현을 검토했다. 별도 모델에 의한 독립 행동 평가, 실제 시험 환경의 설치·모델·제출 검증은 수행하지 않았다.

## PDF

- Codex 운용 가이드: 13쪽, 장별 북마크 13개.
- 서술형 준비 가이드: 12쪽, 장별 북마크 12개.
- 25쪽 전체의 텍스트 추출, 한글 표시, 페이지 경계, 웹 링크를 확인했다.
- 전체 페이지를 렌더링해 배치를 점검하고 코드·키워드 표·출력 형식을 확대 확인했다.
- 코드 블록은 고정폭 글꼴을 사용해 역슬래시가 원화 기호처럼 보이는 문제를 피했다.
- 외부 글꼴 경로 없이 기본 CJK 글꼴로 운용 가이드를 재생성하고 한글 추출을 확인했다.

## 도구가 보장하지 않는 것

audit은 명시한 파일과 실행 기록만 대조한다. 명령의 의미, 등록하지 않은 요구사항, 추적하지 않은 의존성, 사람이 확인해야 하는 UI, 공식 제출 완료는 별도로 확인해야 한다. 로그는 수정 불가능한 감사 기록이 아니고 민감 정보를 자동 제거하지 않는다. run은 지정 명령의 외부 통신을 차단하지 않는다.

공개 문서는 검토 날짜의 자료에 근거한다. 규정·도구 기능은 실제 응시 환경의 최신 안내를 따른다.
