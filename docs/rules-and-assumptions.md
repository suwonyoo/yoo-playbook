## 확인된 내용의 요약

- E1·E3: 제공 환경의 Codex를 사용한다. 개인 API 키·유료 구독·별도 외부 AI 모델 연결은 허용되지 않는다. Astra는 제한된다. 모델 이름은 응시 화면에서 확인하며 로컬 모델 ID를 강제로 설정하지 않는다.
- E3 2쪽: 추가 터미널·분할이 가능하다. Codex의 승인 대기, 실행 중, 완료를 구분한다. 서버 터미널을 유지한다.
- E3 3쪽: 웹 미리보기는 실제 포트·경로와 `0.0.0.0` 바인딩을 확인한다. 3000은 예시다. 필수 파일명과 내용은 실제 과제 안내가 결정한다.
- E1·E3 5쪽: 공개 저장소·Skill·MCP·Plugin 등 자료를 가져올 수 있다. 개인 파일 업로드, 문제·작업 결과 외부 전송, Git push, 제한 우회, Computer Use는 허용되지 않는다.
- U1: 사용한 저장소는 2차 예선 결과 통지 전까지 공개 상태여야 한다. 비공개 저장소 사용이나 외부 결과물로 통째로 대체하는 행위는 불가하다.
- E3 3쪽: 계획·협업 문서는 AI와 작성할 수 있다. 선택 이유·검증·한계를 충실히 담는다. 미리보기 목록은 전체 제출 파일을 뜻하지 않을 수 있다.
- E1·E3 4~5쪽: 과제 최대 180분, 이후 준비 대기 약 5분, 서술형 6문항×5분. 모든 단계는 14:00에 종료된다. 상세 가이드의 화면 속 5문항·최대 10분 표시는 예시로 설명되어 있으므로 실제 화면을 확인한다.
- E1·E3 4쪽: 실제 후속 서술형은 AI·복사 붙여넣기를 사용할 수 없고 이전 문항으로 돌아갈 수 없다. 제출물 확정 후 파일을 바꿀 수 없다.

## 아직 확정하지 않은 것

과제 유형, 필수 스택, 데이터 구조, 배점, 필수 문서명, 자동 채점 방식, 네트워크 패키지 접근 범위, 에이전트 동시 수, 모델별 속도·토큰 예산은 확인되지 않았다. UI 예시가 곧 실제 출제 내용이라는 뜻은 아니다.

이 저장소의 180분 배분안, 역할 분담 수, 요구사항 ID, `.playbook/` 양식, 연습 질문, 웹/데이터 분류는 **준비 전략**이다. 공식 제출 양식이나 채점 기준이라고 표현하지 않는다. 지침이 충돌하면 실제 과제·최신 공지를 우선하고, 업무 의미는 실무자 에이전트, 사용법은 Cofa Helper, 장애는 문제 신고로 확인한다.
