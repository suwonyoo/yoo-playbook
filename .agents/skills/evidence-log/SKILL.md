# 작업 증거 기록

기존 로그·대화·파일·실행 결과를 바탕으로 변경된 부분만 기록한다. 공식 제출 양식이 있으면 그 양식을 우선한다.

- 판단: 문제, 대안, 선택 이유, 감수한 단점, 다시 판단할 조건.
- 협업: AI에게 맡긴 목적, 제안, 본인의 채택/수정/거절, 확인 방법과 결과.
- 검증: 요구사항, 입력, 기대·실제 결과, 명령 또는 수동 행동, 로그·파일 위치, 수행자.
- 한계: 미구현/미검증 범위, 실제 사용자 영향, 다음 확인.

AI의 추론은 테스트 결과가 아니다. AI가 실행한 테스트는 사람의 직접 조작이 아니다. 기록을 뒤늦게 작성하면 시점을 구분하고 빈 증거는 미확인으로 남긴다. 모든 대화를 복사하기보다 결과를 바꾼 사건을 추린다.

출력: 서로 연결된 짧은 기록과 미확인 항목. 실제 시험의 기록은 제공 작업 공간 안에 저장하며 외부 공개 저장소에 전송하지 않는다.
