# 세션 인수인계

목표·실제 마감, 적용 지침, 결정 이유, 현재 코드 위치, 마지막 테스트와 로그, 실패 재현, 서버 터미널·포트, 다음 행동을 남긴다. 읽어야 하는 파일을 구체적으로 지목한다.

완료·진행·미확인 상태를 나누고 실제 디스크 상태로 확인한다. 실행 중인 서버가 새 세션에서도 유지된다고 가정하지 않는다. 세션 ID·비밀·전체 대화를 불필요하게 외부로 옮기지 않는다.

재개할 때 기록부터 읽되 실제 파일·diff·필요한 짧은 검증으로 현재 상태를 확인한다. 기존 완료 작업을 다시 만들지 않는다. 목표가 바뀌지 않았다면 이전 결정과 미완료 작업을 유지한다.
