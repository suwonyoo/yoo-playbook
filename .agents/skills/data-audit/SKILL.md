# 데이터와 계산 확인

원본을 보존하고 작업 파일을 구분한다. 모든 열을 외부 서비스에 보내지 않는다.

- 행의 의미, 키, 자료형, 단위, 기간·시간대, 결측·중복·이상값을 실제 값으로 확인한다.
- 지표의 분자·분모와 제외 조건을 정의한다. 비율의 단순 평균과 전체 합계의 비율을 혼동하지 않는다.
- 조인 전후 행 수·키 중복을 비교한다. 행이 늘어난 원인을 모르면 집계를 확정하지 않는다.
- 손으로 계산 가능한 작은 표를 만들고 결과를 대조한다. 0 분모, 경계 날짜, 결측·빈 집합 중 관련 사례를 포함한다.
- 추천/예측이면 기준선, 입력 가능 시점, 검증 분할을 먼저 정한다. 미래 데이터나 정답 누출이 없는지 확인한다. 규칙 기반 점수와 학습 모델을 구분한다.
- 시각화의 단위·축·필터 조건을 표시한다. 관찰된 상관만으로 인과나 정확도를 주장하지 않는다.

출력: 데이터 점검 요약, 계산 정의, 작은 검증 사례, 결과와 제한. 데이터가 없으면 성능 수치를 만들어 넣지 않는다.
