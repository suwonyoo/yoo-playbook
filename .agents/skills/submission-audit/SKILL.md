# 제출 점검

실제 과제 지침의 필수 항목과 현재 제출 폴더를 대조한다. 이 저장소의 양식명을 공식 필수 파일로 추가하지 않는다.

- 요구사항별 구현·검증·한계를 맞춰 본다. 실패·미실행 항목을 숨기지 않는다.
- 실제 실행 명령과 필수 파일의 존재·내용을 확인한다. worktree·임시 폴더에만 있는 구현을 찾는다.
- 문서의 실행법·기능 설명과 실제 동작이 일치하는지 확인한다. 예시 데이터·가정은 표시한다.
- 사람이 Browser의 핵심 흐름과 에디터 저장 상태·충돌을 직접 확인하도록 구체적인 점검 목록을 제공한다.
- 하네스 audit 성공은 등록된 파일·명령 기록의 정합성만 뜻한다. 전체 품질이나 공식 제출 성공으로 표현하지 않는다.

제출 버튼·감독 화면을 자동 조작하지 않는다. 사람이 미리보기→제출물 확정→후속 서술형→최종 완료를 진행한다. 확정 후 파일 변경이 불가능하며 서술형은 AI 없이 직접 작성한다.
