# 과제 파악

실제 과제 지침과 기존 파일을 먼저 읽는다. 이 준비 도구의 예시를 출제 조건으로 취급하지 않는다.

- 사용자가 누구이며 어떤 결정을 해야 하는지 한 문장으로 적는다.
- 요구사항을 R-001처럼 식별하고 필수/선택, 근거 문장 위치, 성공을 확인할 입력·출력으로 바꾼다.
- 제출 파일명·형식·실행 명령·사용 가능 데이터가 명시되어 있는지 확인한다. 없으면 미확인으로 남긴다.
- 기존 구현, 제공된 데이터, 설치된 도구를 살펴 가장 짧은 핵심 흐름을 선택한다. 읽기만 계속하지 않는다.
- 업무 정의가 불명확하면 실무자 에이전트에 물을 구체적 질문을 정리한다. 도구 사용법은 Cofa Helper, 장애는 문제 신고로 구분한다. 메시지는 사용자가 요청한 경로로만 보낸다.

출력: 필수조건 표, 위험한 가정, 바로 구현할 첫 흐름과 검증 방법. 확인되지 않은 평가 배점이나 예상 문제를 사실처럼 추가하지 않는다.
