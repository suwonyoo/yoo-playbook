# 문서와 산출물 작성

요구한 형식·파일명을 확인한다. 지정되지 않았다면 기존 프로젝트 형식을 따른다. PDF가 필요 없는데 변환 도구 설치에 시간을 쓰지 않는다.

문서의 주장은 구현·데이터·검증과 연결한다. 예시 값은 예시로 표시하고 임의의 성능·효과·사용자 평가를 넣지 않는다. 실행 안내는 현재 파일과 명령으로 검증한다.

표는 단위·기준 기간·누락 처리·출처를 표시한다. 문서는 목적→실행/확인 방법→결과→한계 순으로 읽히게 한다. 긴 로그와 반복된 대화는 근거 파일로 분리한다.

PDF를 만들면 한글 글꼴·수식·표 줄바꿈·페이지 잘림을 렌더링해 확인한다. 텍스트 추출만 성공했다고 표시 품질을 통과시키지 않는다. 외부 변환 서비스로 시험 파일을 전송하지 않는다.
