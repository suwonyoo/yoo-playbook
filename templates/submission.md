# 제출 전 사람이 확인할 항목

- [ ] 실제 과제의 필수 파일명·경로·형식을 대조했다.
- [ ] 핵심 사용자 흐름을 제공된 Browser에서 직접 실행했다.
- [ ] 필요한 명령·설치·시작 순서를 실제 환경에서 확인했다.
- [ ] 코드·문서가 서로 모순되지 않는다. 미검증 범위를 표시했다.
- [ ] 에디터의 저장 실패·외부 변경 충돌을 해결했다.
- [ ] 제출 미리보기의 생략 가능성을 알고 필수 파일을 직접 확인했다.
- [ ] 제출물 확정 후 수정 불가를 이해했다.
- [ ] 이후 서술형은 AI 없이 직접 작성한다.
- [ ] 마지막 완료 화면에서 제출 ID·시각·파일 수·크기를 확인한다.

실제 체크한 항목에만 표시한다. 이 문서가 제출 버튼을 대신하지 않는다.
